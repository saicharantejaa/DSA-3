Mod 1/6

HashMap / HashSet

            O(n)
            
Skill extraction & deduplication from resumes.

🌳

            
Trie

            O(k)
            
Prefix tree for instant skill autocomplete.

          

          

            
Mod 3

            
📐

            
Edit Distance DP

            O(m·n)
            
Wagner-Fischer fuzzy skill matching.

          

          

            
Mod 3

            
📋

            
LCS

            O(m·n)
            
Longest Common Subsequence — resume vs JD.

          

          

            
Mod 4

            
🔀

            
Merge Sort

            O(n log n)
            
Stable ranking of candidates by score.

          

          

            
Mod 4

            
⚡

            
Quick Sort

            O(n log n)
            
In-place sort used in algorithm race.

🏔️

            
Max-Heap / PQ

            O(log n)
            
Top-K shortlisting with animated heap tree.

          

          

            
Mod 6

            
🕸️

            
Graph BFS

            O(V+E)
            
Related-skill partial credit via BFS traversal.
