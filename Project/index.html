Core capabilities

Everything your hiring pipeline needs

Skill Extraction

Parses free-text resumes and job descriptions. Uses a HashSet to deduplicate skills and normalize to lowercase — no manual tagging needed.

Edit Distance Fit Score

Wagner-Fischer Dynamic Programming (DSA-3 Module 3) computes fuzzy string alignment, handling typos, synonyms, and variations in O(m·n).

Merge Sort Ranking

All candidates are sorted by score using Merge Sort (O(n log n)). Top-K shortlisting uses a Max-Heap Priority Queue.

Skill Gap Analysis

Shows exactly which skills a candidate has (matched) vs. which are missing — so you can make informed decisions fast.

Recruiter Dashboard

Clean UI to post jobs, view ranked candidates, filter by score threshold, and manage your shortlist in one place.

Java REST API

Pure Java backend (no frameworks) using the built-in HttpServer. Exposes /api/candidates and /api/match endpoints.

Pipeline

How matching works

01

Post a Job

Enter a job title and paste the required skills (comma-separated). Stored as a HashSet<String> in Java.

02

Add Candidates

Enter candidate name and their skills. SkillExtractor.java normalizes and deduplicates via a HashMap.

03

Score

EditDistanceScorer.java computes Wagner-Fischer DP edit distance to fuzzy match skills against job requirements.

04

Rank & Shortlist

CandidateRanker.java sorts by score using Merge Sort. Top candidates shown first.

DSA Reference

Algorithms powering TalentMatch

HashMap / HashSet

SkillExtractor.java — O(n) skill normalization. Deduplication in constant time using hash-based sets (Module 1 / 6).

Edit Distance (Wagner-Fischer DP)

EditDistanceScorer.java — Dynamic programming sequence alignment (Module 3). Handles typos, variations, and fuzzy matching.

Merge Sort

CandidateRanker.java — O(n log n) stable sort by score descending. Best for ranked leaderboards.
