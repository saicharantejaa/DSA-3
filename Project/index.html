Module 1 / 6 · Hash Structures

Constant-Time Skill Tokenization

SkillExtractor.java parses unstructured text and maps tech keywords to normalized tokens. It uses a HashSet<String> to eliminate duplicates in O(1) expected time, standardizing syntax variations like "ReactJS" and "react".

Time: O(n) Space: O(k) Lookup: O(1) amortized
SkillExtractor.java Java 17 
public class SkillExtractor {
  public static Set<String> extract(String raw) {
    Set<String> skills = new HashSet<>();
    for (String token : raw.split(",")) {
      String normalized = token.trim().toLowerCase();
      if (!normalized.isEmpty()) {
        skills.add(normalized); // O(1) deduplication
      }
    }
    return skills;
  }
}
Module 3 · Advanced DP

Fuzzy Edit Distance Scoring

EditDistanceScorer.java computes the minimum edit operations (insertions, deletions, substitutions) required to transform one skill string into another using an optimal 2D table. Normalized by max string length with a threshold of 0.35.

Time: O(m·n) Space: O(m·n) Threshold: ≤ 0.35
EditDistanceScorer.java Java 17 
public static int editDistance(String a, String b) {
  int m = a.length(), n = b.length();
  int[][] dp = new int[m + 1][n + 1];
  for (int i = 0; i <= m; i++) dp[i][0] = i;
  for (int j = 0; j <= n; j++) dp[0][j] = j;

  for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
      int cost = (a.charAt(i - 1) == b.charAt(j - 1)) ? 0 : 1;
      dp[i][j] = Math.min(dp[i - 1][j] + 1,
                 Math.min(dp[i][j - 1] + 1, dp[i - 1][j - 1] + cost));
    }
  }
  return dp[m][n];
}
Module 2 · Divide and Conquer

Stable Merge Sort Ranking

CandidateRanker.java sorts candidate scores in descending order. Because recruitment requires deterministic fairness, Merge Sort's stability guarantee ensures candidates with identical scores maintain their original submission order.

Worst Case: O(n log n) Space: O(n) Stability: Guaranteed
CandidateRanker.java Java 17 
public static void mergeSort(List<CandidateResult> list, int l, int r) {
  if (l < r) {
    int m = l + (r - l) / 2;
    mergeSort(list, l, m);
    mergeSort(list, m + 1, r);
    merge(list, l, m, r); // Stable merge step
  }
}
